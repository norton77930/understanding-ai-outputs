# understanding-ai-outputs

Agent skills that make LLM outputs easier to understand, based on Andrej Karpathy's post
(see `reference/karpathy-x-post.md`).

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues (`norton77930/understanding-ai-outputs`), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` and `docs/adr/`, created lazily. See `docs/agents/domain.md`.
