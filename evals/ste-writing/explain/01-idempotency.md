## Request

用 STE 解釋：什麼是冪等性（idempotency），以及為什麼 API 的重試需要它。

## Reader should understand

- 冪等的操作執行一次和執行很多次，最後的結果相同。例如「把餘額設成 500」是冪等的，「把餘額加 100」不是。
- 請求逾時的時候，用戶端不知道伺服器有沒有處理完，所以常常會重送同一個請求。
- 不是冪等的操作被重送時，同一件事可能發生兩次（例如餘額被加了兩次 100）。
- 常見的做法是：用戶端替每個請求附上一個唯一的冪等鍵（idempotency key）；伺服器收到重複的鍵時，不再執行一次，而是回傳第一次的結果。
