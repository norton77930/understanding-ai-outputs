In order to restore the application database from a backup, a number of steps must be performed by the administrator in the correct sequence. Firstly, the application service must be stopped, and it should be verified that no active connections to the database remain, because a restore that is started while connections are open may result in corrupted data. Subsequently, the most recent backup file is located in the backup directory and copied to the restore location, after which the file integrity is confirmed by comparison of the checksum with the value that is recorded in the backup log. When the checksum has been confirmed, the restore utility is started, and the progress of the operation is monitored until a completion message is displayed. Finally, the application service is restarted and the login page is tested.
