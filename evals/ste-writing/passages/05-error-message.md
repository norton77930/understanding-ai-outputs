The error message `ERR_CERT_EXPIRED: certificate has expired` is displayed by the client when the security certificate that was presented by the server is found to be no longer valid at the time of the connection attempt. This situation is most frequently caused by a failure on the part of the server administrator to renew the certificate prior to its expiration date, but it may also be caused by an incorrectly configured system clock on the machine of the user, since the validity period of the certificate is compared with the local time. It is recommended that the system date and time are verified first, and, if the clock is determined to be correct, that the administrator of the server is contacted in order to request that the certificate be renewed. The connection should not be forced by disabling certificate verification.
