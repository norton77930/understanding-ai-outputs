The `fetch_records` method of the `RecordClient` class is utilized in order to retrieve a collection of records from the remote storage service. Prior to the invocation of the method, it is necessary that a valid session token has been obtained by the caller, because requests that are submitted without authentication will be rejected by the server. The `limit` parameter, which is optional and defaults to 100, is used to specify the maximum number of records that are returned in a single response, and a value that is greater than 500 will be silently reduced by the service. In the event that the requested collection is empty, an empty list is returned, and no exception is raised by the client library. If a network interruption is experienced during the transfer, a `ConnectionLost` error is raised.
