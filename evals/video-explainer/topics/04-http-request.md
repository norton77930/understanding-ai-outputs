## Source

You type a web address and press Enter. What happens next takes less than a second. First, your browser asks a DNS server to turn the name into an IP address, like looking up a phone number. Next, it opens a connection to that address, and for a secure site it also sets up encryption. Then it sends an HTTP request: a method such as GET, the path you want, and some headers. The server reads the request, builds a response, and sends it back with a status code. A 200 means success, and a 404 means the page was not found. The response body holds the HTML. Your browser reads it, asks for any images or scripts it needs, and draws the page.

## Viewer should understand

- The browser first uses DNS to turn the site name into an IP address.
- It opens a connection (with encryption for HTTPS) and sends a request made of a method, a path and headers.
- The server replies with a status code (such as 200 or 404) and a body, usually HTML.
- The browser then fetches the extra files the page needs and draws the result.
